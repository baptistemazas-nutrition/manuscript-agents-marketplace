# Researcher Workflow Map — the whole suite at a glance

Where every step of writing a scientific article lives across manuscript-agents.

| Stage | What you do | Skill |
|---|---|---|
| 0. Find/sharpen the question | framing, FINER, feasibility, Socratic dialogue | `deep-research` |
| 1. Review the literature | systematic search, source verification, synthesis, meta-analysis | `deep-research` |
| 2. Analyze the data | data→results: descriptives, models, survival, ML, figures, reproducible code | `manuscript-statistics` |
| 3. Pick the reporting standard | CONSORT/STROBE/PRISMA/CARE/ARRIVE/TRIPOD/SRQR/SQUIRE | `manuscript-guidelines` |
| 4. Write the paper | outline, draft, abstract (incl. bilingual/lay), style calibration, anti-AI-pattern | `academic-paper` |
| 5. Get the citations right | source-claim coherence, cross-section consistency; styles & Zotero | `manuscript-citations`, `academic-paper` |
| 6. Self-review / simulate peer review | EIC + reviewers + devil's advocate | `academic-paper-reviewer` |
| 7. Run it all end-to-end with gates | research→write→integrity→review→revise→finalize | `academic-pipeline` |
| 8. Select journal & submit | fit, predatory screen, cover letter, back matter, suggested reviewers | `journal-submission` |
| 9. Respond to reviewers & revise | point-by-point response, rebuttal, R&R | `journal-submission` + `academic-paper` |
| 10. Accept, publish, promote | proofs, license/OA, data/code DOIs, ORCID, preprint, promotion | `journal-submission` |

Cross-cutting: research integrity & publication ethics, open science/reproducibility, academic English/readability, discoverability (title/keywords) — see the references in `journal-submission` and `academic-paper`.
