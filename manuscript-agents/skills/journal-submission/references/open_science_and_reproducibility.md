# Open Science & Reproducibility

Increasingly required by journals and funders; also makes the work more citable and trusted.

## Data availability
- Deposit data in a recognized repository (Zenodo, OSF, Figshare, Dryad, or domain repos like GEO/SRA, GenBank, ICPSR) → get a **DOI**.
- Write a **data availability statement**: where, how to access, any restrictions (ethics/consent) and the controlled-access route.
- Make data **FAIR**: Findable (DOI + metadata), Accessible, Interoperable (open formats), Reusable (license + data dictionary).

## Code availability
- Public repository (GitHub/GitLab) with a README, environment/versions, and a **license** (e.g., MIT/BSD/Apache for code, CC-BY for data).
- Archive a release for citation (Zenodo–GitHub integration mints a DOI).
- Pair with the analysis reproducibility bundle from `manuscript-statistics` (script, seed, versions, data dictionary).

## Preprints
- Posting to **arXiv / bioRxiv / medRxiv / SSRN** establishes priority and invites feedback. Check the target journal's preprint policy first (most allow it; cite the preprint DOI in the cover letter).

## Registration
- Pre-register studies/analysis plans where applicable (OSF, ClinicalTrials.gov for trials, PROSPERO for systematic reviews). Registered Reports get in-principle acceptance before results.

## Identifiers
- **ORCID** for every author; RAiD/ROR for organizations; cite datasets and software like papers.
