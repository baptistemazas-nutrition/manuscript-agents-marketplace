# Pre-Submission Checklist (the back matter)

Run before hitting submit; many desk rejections are missing pieces, not bad science.

## Manuscript conformance
- [ ] Matches the journal's article type, structure, word/figure/table limits.
- [ ] Reference style exactly per author guidelines (see academic-paper `reference_styles_and_managers.md`).
- [ ] Title, running head, keywords, abstract format (structured?) per spec.
- [ ] Figures at required resolution/format; tables editable; legends complete.
- [ ] Reporting checklist for the design attached (CONSORT/STROBE/PRISMA/CARE/ARRIVE/TRIPOD/SRQR/SQUIRE) — from `manuscript-guidelines`.

## Required statements (the "back matter")
- [ ] **Author contributions** — CRediT taxonomy (conceptualization, methodology, analysis, writing, etc.).
- [ ] **Conflicts of interest** — all authors; "none" if none.
- [ ] **Funding** — grant numbers and funders; role of funder.
- [ ] **Ethics** — IRB/IACUC approval + number, or waiver; informed consent; consent to publish (case reports).
- [ ] **Data availability statement** — where data live (repository + DOI/accession), or why restricted.
- [ ] **Code availability** — repository link, version, license (esp. for analyses/models).
- [ ] **ORCID** for authors; correct affiliations; corresponding author designated.
- [ ] **AI-use disclosure** per journal policy.
- [ ] Acknowledgements (non-author contributors, with permission).

## Logistics
- [ ] Suggested reviewers (real, non-conflicted, with emails) and any excluded reviewers + reason.
- [ ] Cover letter tailored to THIS journal.
- [ ] Preprint policy checked; not under review elsewhere (no dual submission).
- [ ] All co-authors have approved the final version and the author list/order.
