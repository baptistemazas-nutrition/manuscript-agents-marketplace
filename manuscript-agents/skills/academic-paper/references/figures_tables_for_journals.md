# Figures & Tables for Journals

Figures are read before text; make them self-explanatory and submission-ready.

## Design
- One message per figure; title/caption states n, the test, and what error bars mean.
- Show data + uncertainty (points/box/violin + CIs), not bars-of-means alone (see manuscript-statistics visualization).
- **Color-blind-safe** palettes; don't encode meaning by color alone (add shape/pattern/labels). Sufficient contrast and font size.
- No chart-junk, no 3D for 2D data, no truncated axes that exaggerate effects.

## Technical specs (check author guidelines)
- Resolution: ~300 dpi for photos/halftone, ~600-1200 dpi for line art; vector (EPS/PDF/SVG) preferred for plots.
- Formats: TIFF/EPS/PDF often required; RGB vs. CMYK per journal; embed fonts.
- Size to column width; legible at print size; consistent fonts/styles across figures.

## Tables
- For precise values and many comparisons (figures for trends/patterns). Editable (not images).
- Clear headers with units; align decimals; define all abbreviations in a footnote; report effect sizes + CIs.
- Don't duplicate the same data in a table and a figure.

## Accessibility & integrity
- Alt-text/descriptive captions. No selective or non-uniform image manipulation (see publication ethics); keep originals.
