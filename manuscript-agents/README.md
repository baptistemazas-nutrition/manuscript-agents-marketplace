# Manuscript Agents
Eight skills covering the full scientific-manuscript lifecycle, from research question to published paper:
deep-research, manuscript-statistics (with a bundled Python analysis engine), manuscript-guidelines (EQUATOR),
academic-paper, manuscript-citations, academic-paper-reviewer, academic-pipeline (orchestrator), and
journal-submission (journal selection, cover letter, response to reviewers, submission checklist, open science, publication ethics).
Ask in natural language and the matching skill triggers. See journal-submission/references/researcher_workflow_map.md for the map.
